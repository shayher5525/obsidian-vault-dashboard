# Vault Dashboard X

[English](../README.md) · **中文** · [日本語](README_ja.md) · [한국어](README_ko.md) · [Français](README_fr.md) · [Español](README_es.md) · [Italiano](README_it.md)

一个 Obsidian 库的仪表盘：活动热力图、文件夹分布视图，以及可配置的「快捷入口」 —— 全部集中在一个面板中。

## 功能特性

- **活动热力图** —— GitHub 风格的贡献网格，展示你的库（或变更日志）随时间推移的活跃程度，支持 `全部 / 30 天 / 7 天` 范围。最新的周在最左侧。
- **文件夹分布** —— 按顶层文件夹对你的笔记进行分解，包含下钻行、占父级比例条和「本月新增」计数。
- **快捷入口** —— 最多 5 个可配置模块。每个指向一个文件夹，列出其中最近修改的笔记，并把你勾选的子文件夹显示为二级标签。文件夹名按磁盘上的原样显示。
- **两种数据源** —— 通用的「笔记活动」源（适用于任何库）和可选的「变更日志」解析器（用于 Markdown 变更日志）。
- **三套主题** —— Apple、Y2K Console 和 Starbucks Café。
- **国际化** —— 英语（默认）、简体中文、繁体中文、日语、韩语、法语、西班牙语和意大利语。

## 数据源

### 笔记活动（默认）

每篇笔记贡献一个「活动日」，按以下回退链解析：

1. Frontmatter 字段 `updated`（字段名可配置）。
2. Frontmatter 的 `created` / `date`。
3. 文件名中的 `YYYY-MM-DD` 前缀。
4. 文件修改时间（`mtime`）—— **默认关闭**；可在设置中启用。

笔记活动在任何库中开箱即用，无需额外配置。

### 变更日志

统计一个或多个变更日志文件中的条目。解析器读取 `## YYYY-MM-DD` 小节，并统计每个日期下的顶层列表项：

```markdown
## 2026-08-23

- 发布七月报告
- 修正风格指南中的一个笔误

> 注意：日期小节下的引用块会被忽略。
```

每个文件可以是单篇笔记，也可以是一个文件夹（解析其中全部 `.md` 文件，非递归）。

## 使用

从功能区图标或 **「打开仪表盘」** 命令打开仪表盘。

- **概览** 标签页 —— 热力图和汇总卡片。
- **文件夹** 标签页 —— 文件夹分布。
- 点击变更日志热力图的单元格可跳转到当天的章节（仅变更日志模式）。
- 点击文件夹行可下钻。

## 设置

| 设置项 | 说明 |
| --- | --- |
| 语言 | 设置页和仪表盘的界面语言。 |
| 外观 | 视觉风格：Apple、Y2K Console 或 Starbucks Café。 |
| 活动数据源 | 笔记活动或变更日志。 |
| 活动日期字段 | 笔记活动回退链中最先使用的 Frontmatter 字段。 |
| 回退到文件修改时间 | 将 `mtime` 作为最终回退（默认关闭）。 |
| 变更日志路径 | 变更日志模式下解析的文件/文件夹。 |
| 快捷入口 | 最多 5 个模块；每个指向一个文件夹并列出其最近笔记。 |
| 显示的子目录 | 逐模块勾选哪些子文件夹作为二级标签。全部勾选时，此后新增的子文件夹会自动出现。 |

## 安装

### 从社区目录安装（发布后）

从 **设置 → 社区插件** 安装「Vault Dashboard X」，然后启用它。

### 手动安装

1. 从最新版本下载 `main.js`、`manifest.json` 和 `styles.css`。
2. 在你的库中创建 `.obsidian/plugins/vault-dashboard-x/`。
3. 将三个文件复制到该文件夹。
4. 在 **设置 → 社区插件** 下启用该插件。

## 开发

**没有构建步骤** —— `main.js` 就是插件产物。编辑后，在 Obsidian 中禁用并重新启用插件（或运行 `Reload app`）以生效。

- 使用 `npm version <patch|minor|major>` 提升版本；它会自动同步 `manifest.json` 和 `versions.json`。
- 使用 `node test/harness.js` 运行离线数据层健全性检查。

发布标签 **必须等于** `manifest.json` 中的 `version`，不带 `v` 前缀；`main.js`、`manifest.json` 和 `styles.css` 作为单独的发布附件提供。
