# Vault Dashboard X

[English](../README.md) · [中文](README_zh.md) · **日本語** · [한국어](README_ko.md) · [Français](README_fr.md) · [Español](README_es.md) · [Italiano](README_it.md)

Obsidian ボールトのためのダッシュボード：アクティビティヒートマップ、フォルダ分布ビュー、設定可能な「クイックアクセス」を、1 つのペインにまとめました。

## 機能

- **アクティビティヒートマップ** —— GitHub 風のコントリビューショングリッドで、ボールト（またはチェンジログ）の時間経過に沿ったアクティブ度を表示。`すべて / 30 日 / 7 日` の範囲に対応。最新の週が左端です。
- **フォルダ分布** —— トップレベルフォルダごとのノート内訳。ドリルダウン行、親に対する割合バー、「今月の新規」件数を備えています。
- **クイックアクセス** —— 最大 5 個の設定可能なブロック。それぞれがフォルダを指し、最近変更されたノートを一覧表示し、選んだサブフォルダを第 2 階層のタブとして表示します。フォルダー名はディスク上のまま表示されます。
- **2 つのデータソース** —— 汎用の「ノートアクティビティ」ソース（どのボールトでも動作）と、Markdown チェンジログ用のオプションの「チェンジログ」パーサー。
- **3 つのテーマ** —— Apple、Y2K Console、Starbucks Café。
- **国際化** —— 英語（デフォルト）、簡体字中国語、繁体字中国語、日本語、韓国語、フランス語、スペイン語、イタリア語。

## データソース

### ノートアクティビティ（デフォルト）

各ノートは 1 つの「アクティビティ日」に寄与し、次のフォールバックチェーンで解決されます。

1. Frontmatter の `updated` フィールド（フィールド名は設定可能）。
2. Frontmatter の `created` / `date`。
3. ファイル名の `YYYY-MM-DD` プレフィックス。
4. ファイルの変更時刻（`mtime`）—— **既定でオン**。多くの保管庫のノートには frontmatter の日付もファイル名の日付もないため、この段がないとヒートマップはほぼ空になります。同期が変更時刻を一括更新して偽の山が出る場合は、設定でオフにしてください。

ノートアクティビティは追加設定なしでどのボールトでもそのまま動作します。

### チェンジログ

1 つ以上のチェンジログファイルのエントリをカウントします。パーサーは `## YYYY-MM-DD` セクションを読み取り、各日付の下のトップレベルリスト項目をカウントします。

```markdown
## 2026-08-23

- 7月のレポートを公開
- スタイルガイドの誤字を修正

> 注：日付セクションの下のブロッククォートは無視されます。
```

各ファイルは単一のノートでも、フォルダ（内部のすべての `.md` ファイル、非再帰）でも構いません。

## 使い方

リボンアイコンまたは **「ダッシュボードを開く」** コマンドからダッシュボードを開きます。

- **概要** タブ —— ヒートマップとサマリーカード。
- **フォルダ** タブ —— フォルダ分布。
- チェンジログのヒートマップのセルをクリックすると、その日のセクションにジャンプします（チェンジログモードのみ）。
- フォルダ行をクリックするとドリルダウンします。

## 設定

| 設定 | 説明 |
| --- | --- |
| 言語 | 設定ページとダッシュボードのインターフェース言語。 |
| 外観 | ビジュアルスタイル：Apple、Y2K Console、Starbucks Café。 |
| アクティビティデータソース | ノートアクティビティまたはチェンジログ。 |
| アクティビティ日付フィールド | ノートアクティビティのフォールバックチェーンで最初に使用される Frontmatter フィールド。 |
| ファイル変更時刻にフォールバック | `mtime` を最終フォールバックとして使用（既定はオン）。 |
| チェンジログパス | チェンジログモードで解析されるファイル/フォルダ。 |
| クイックアクセス | 最大 5 ブロック。それぞれがフォルダを指し、最近のノートを一覧表示します。 |
| 表示するサブフォルダー | ブロックごとに、第 2 階層のタブにするサブフォルダーを選びます。すべて選ぶと、以後追加されたものも自動的に表示されます。 |

## インストール

### コミュニティディレクトリから（公開後）

**設定 → コミュニティプラグイン** から「Vault Dashboard X」をインストールし、有効化します。

### 手動

1. 最新リリースから `main.js`、`manifest.json`、`styles.css` をダウンロードします。
2. ボールトに `.obsidian/plugins/vault-dashboard-x/` を作成します。
3. 3 つのファイルをそのフォルダにコピーします。
4. **設定 → コミュニティプラグイン** でプラグインを有効化します。

## 開発

**ビルドステップはありません** —— `main.js` がプラグイン成果物です。編集後、Obsidian でプラグインを無効化して再度有効化する（または `Reload app` を実行する）と変更が反映されます。

- バージョンは `npm version <patch|minor|major>` で上げます。`manifest.json` と `versions.json` が自動的に同期されます。
- オフラインのデータ層健全性チェックは `node test/harness.js` で実行します。

リリースタグは **`manifest.json` の `version` と一致させ、`v` プレフィックスを付けない**必要があります。`main.js`、`manifest.json`、`styles.css` は個別のリリースアセットとして添付されます。
