## バージョン規約

本プロジェクトはセマンティックバージョニング（MAJOR.MINOR.PATCH）に従います。

| 区分 | 上がるとき | 例 |
| --- | --- | --- |
| MAJOR | 破壊的変更：`data.json` や設定の非互換、手動移行が必要、機能の削除 | 互換読み込みなしで設定項目を改名 |
| MINOR | 機能追加、ペインやタブの追加、目に見える操作・見た目の刷新 | クイックアクセスのブロックを追加 |
| PATCH | バグ修正、文言修正、スタイルの微調整（できることは変わらない） | 色階が上書きされる不具合の修正、余白の調整 |

バージョンの正は `manifest.json` の `version` です。リリースタグはこれと一致し、`v` 接頭辞は付けません。

## [0.15.0] — 2026-09-02

### 追加

- 新外観 **ブラックステージ**（`sony`）を追加。`AA_WorkMaterial 工作资料/91_DesignFiles 设计文件/2026-09-02_索尼风格视觉设计规范.md` v1.0（2007 年のソニー米国識別マニュアルに由来）に基づき、「黒場の基底・開放フレーム・幾何学サンセリフ・一点の色光」という視覚文法だけを借用。ロゴ、スローガン、商用ライセンス書体は使わず、ITC Avant Garde は Poppins / Jost / Questrial / 源ノ角ゴシックの代替スタックに置き換えています。基底は柔らかい黒ではなく純黒 `#000000`。奥行きは影ではなく `#000000` → `#0D0D0D` → `#1A1A1A` の三段の明度で表し、角丸はゼロ（操作部品でも最大 2px）。強調色は一画面につき一つだけで、ダークは ocean `#00A4E8`（黒地で約 7.4:1）、ライトは slate `#165B65`。ライトで ocean を使わないのは、白地では約 2.7:1 まで落ちて文字を支えられないためで、規範はダークの配色を反転するのではなくコントラストの再確認を求めています。強調色は面を塗らないため、選択状態は塗りつぶしのピルではなく 2px のスライド下線、カードの数値は黒か白のまま、色が付く文字はリンクだけです。ダークが規範の正であり、ライトは規範自身が文字密度の高いページに定めた反転規定に従います。
- オフラインテストにブラックステージの守りを五つ追加。いずれも規範の硬規則そのままで、色板の閉集合、`rgba()` による調色の禁止（色は 100% で使う）、影なし、角丸 ≤ 2px、八つの基準色の宣言必須。

### 変更

- 7 言語の README を「5 つのテーマ」に更新。

## [0.14.0] — 2026-09-01

### 追加

- 新外観 **ポップファストフード**（`fastfood`）を追加。`AA_WorkMaterial 工作资料/91_DesignFiles 设计文件/2026-09-01_麦当劳风格视觉设计规范.md` v1.0 に基づき、Gold `#FFBC0D`、Red `#DB0007`、White、改編中性色（`#1A1A1A`、`#5C5C5C`、`#E6E6E6`、`#242424`）だけで構成。Speedee、アーチ、ワードマークは使わず色の文法のみ借用。ライトは White 画布 + Gold 顶栏 + 黒字で Red はアクティブ状態・重要データ・ヒートピークのみ（「金が面、赤が点」）。ダークは `#1A1A1A` + `#242424` + Gold をアクセントと文字色に（深色モードで Gold が文字色になる唯一の例外）。ヒートマップは gold-tint → gold → red。

### 変更

- `modern` 外観を **Apple → ミニマルテック** に改名（他言語の等価訳も同期）。内部 id `modern` と CSS クラス `vdash-style-modern` は不変で `data.json` の移行不要。
- `starbucks` 外観を **Starbucks Café → コーヒーハウス** に改名。内部 id `starbucks` と CSS クラス `vdash-style-starbucks` は不変。
- 7 言語の README を「4 つのテーマ」に更新し新名称を明記。

## [0.13.0] — 2026-09-01

### 追加

- オフラインテストに Starbucks 色域ガードを追加。8 つの標準 HEX をすべて宣言し、それ以外の HEX を使わず、透過色も同じ 8 色の RGB から派生することを検証します。

### 変更

- **「Starbucks Café」を v2.0 視覚仕様に基づき再構築。** primitive は `#006241`、`#00754A`、`#D4E9E2`、`#1E3932`、黒、`#F2F0EB`、`#F9F9F9`、白の 8 色だけに限定。従来の独自グリーン、コーヒーブラウン、ベージュ、無関係なグラフ色を削除し、semantic／component token、ダークモード、影、透過状態を同じ色板から派生させました。8px の間隔・角丸スケールと 44px の操作部品下限にも揃え、ヒートマップセルにアクセシブル名とクリック可能時のキーボード操作を追加しました。

## [0.12.1] — 2026-09-01

### 変更

- 設定の文言から作者個人の保管庫を指す表現を削除。「変更履歴」は「誰向けか・どう数えるか」で説明するようになりました。同じ前提を含むコードコメントも整理（本プラグインはビルド工程がなく `main.js` がそのまま読まれるため）。
- README の言語ごとに変更履歴の翻訳を `docs/` に追加し、各 README から対応言語へリンク。ルートの `CHANGELOG.md` は英語になりました。

## [0.12.0] — 2026-09-01

### 変更

- **`useMtime` の既定をオンに変更。** 多くの保管庫のノートには frontmatter の日付もファイル名の日付もなく、オフのままではヒートマップがほぼ空になり、入れた直後に真っ白な画面が出てしまうためです。同期による偽の山は目に見えて説明でき、スイッチで切れます。**既存の設定は影響を受けません。**
- ブロックが 1 つだけのとき、クイックアクセスの見出しが「クイックアクセス · ブロック名」になりました。従来は 1 つだけだと第 1 階層のタブを描かないため、そのフォルダー名がどこにも出ませんでした。

## [0.10.0] — 2026-09-01

### 追加

- クイックアクセスの各ブロックで、フォルダー直下のサブフォルダーを一覧・選択し、第 2 階層のタブにするものを決められます。すべて選ぶと、以後追加されたサブフォルダーも自動的に表示されます。
- 選択欄は `<details>` の折りたたみに収納。既定は閉じた状態で、見出しに「すべて N 件」または「N 件中 n 件を選択」と表示します。

### 変更

- **フォルダー名の連番接頭辞の除去を廃止し、名前をそのまま表示します。** 旧処理は作者の命名規約に合わせたもので、他の利用者では `2024_Q1 Reports` が `Reports` になるなど、連番だけでなく最初の語まで消えていました。短い名前が必要なら「表示名」に入力してください。
- 設定ページのクイックアクセス欄の左端を、見出しや標準の設定行と揃えました。

## [0.9.0] — 2026-08-29
