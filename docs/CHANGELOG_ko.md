## 버전 규칙

이 프로젝트는 시맨틱 버저닝(MAJOR.MINOR.PATCH)을 따릅니다.

| 구분 | 올라가는 때 | 예 |
| --- | --- | --- |
| MAJOR | 호환성이 깨지는 변경: `data.json`이나 설정 비호환, 수동 마이그레이션 필요, 기능 제거 | 호환 읽기 없이 설정 항목 이름 변경 |
| MINOR | 기능 추가, 창이나 탭 추가, 눈에 보이는 상호작용·시각 개편 | 바로가기 블록 추가 |
| PATCH | 버그 수정, 문구 수정, 스타일 미세 조정(동작은 그대로) | 색 단계가 덮이는 문제 수정, 여백 조정 |

버전의 기준은 `manifest.json`의 `version`이며, 릴리스 태그는 이와 같고 `v` 접두사를 붙이지 않습니다.

## [0.15.0] — 2026-09-02

### 추가

- 새 외관 **블랙 스테이지**(`sony`)를 추가. `AA_WorkMaterial 工作资料/91_DesignFiles 设计文件/2026-09-02_索尼风格视觉设计规范.md` v1.0(2007년 소니 미국 아이덴티티 매뉴얼에서 유래)에 따라 '검은 바탕, 열린 프레임, 기하학적 산세리프, 한 점의 색광'이라는 시각 문법만 빌렸습니다. 로고, 슬로건, 상업용 라이선스 서체는 쓰지 않으며 ITC Avant Garde는 Poppins / Jost / Questrial / 본고딕 대체 스택으로 바꿨습니다. 바탕은 부드러운 검정이 아니라 순수한 `#000000`입니다. 깊이는 그림자가 아니라 `#000000` → `#0D0D0D` → `#1A1A1A` 세 단계 명도로 표현하고, 모서리는 각지게(컨트롤도 최대 2px) 처리했습니다. 강조색은 한 화면에 하나뿐이며 다크는 ocean `#00A4E8`(검정 위 약 7.4:1), 라이트는 slate `#165B65`입니다. 라이트에서 ocean을 쓰지 않는 이유는 흰 바탕에서 약 2.7:1까지 떨어져 글자를 감당할 수 없기 때문으로, 규범은 다크 팔레트를 뒤집는 대신 대비를 다시 확인하도록 요구합니다. 강조색은 면을 채우지 않으므로 선택 상태는 채워진 알약이 아니라 2px 슬라이딩 밑줄이고, 카드 숫자는 검정 또는 흰색을 유지하며 색이 들어가는 글자는 링크뿐입니다. 다크가 규범의 정본이고 라이트는 규범이 글자 밀도가 높은 페이지에 정한 반전 규정을 따릅니다.
- 오프라인 테스트에 블랙 스테이지 검사 다섯 개를 추가했습니다. 모두 규범의 강제 규칙 그대로로, 색상 팔레트 폐집합, `rgba()` 조색 금지(색은 100%로 사용), 그림자 없음, 모서리 ≤ 2px, 여덟 기준색 선언 필수입니다.

### 변경

- 7개 README를 '다섯 가지 테마'로 갱신.

## [0.14.0] — 2026-09-01

Speedee, 아치, 워드마크 없이 색 문법만 차용. 라이트는 White + Gold 상단바 + 흑색이며 Red는 활성 상태·주요 데이터·히트 피크에만(「금이 면, 적이 점」). 다크는 `#1A1A1A` + `#242424` + Gold를 강조와 문자색으로(다크 모드에서 Gold가 문자색이 되는 유일한 예외). 히트맵은 gold-tint → gold → red.

- `starbucks` 외관을 **Starbucks Café → 커피 하우스**로 개명. 내부 id `starbucks`와 CSS 클래스 `vdash-style-starbucks`는 불변.

## [0.10.0] — 2026-09-01

### 추가

- 바로가기의 각 블록에서 폴더 바로 아래의 하위 폴더를 나열·선택해, 어떤 것을 2단계 탭으로 삼을지 정할 수 있습니다. 모두 선택하면 이후 추가된 하위 폴더도 자동으로 나타납니다.

- 설정 페이지의 바로가기 영역 왼쪽 끝을 제목·기본 설정 행과 맞췄습니다.
