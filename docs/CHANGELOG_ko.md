# Vault Dashboard X 변경 기록

[English](../CHANGELOG.md) · [中文](CHANGELOG_zh.md) · [日本語](CHANGELOG_ja.md) · **한국어** · [Français](CHANGELOG_fr.md) · [Español](CHANGELOG_es.md) · [Italiano](CHANGELOG_it.md)

> 이 번역은 각 버전의 요점을 정리한 것입니다. 판단의 배경까지 담긴 전문은 [영어판](../CHANGELOG.md)을 참고하세요.

## 버전 규칙

이 프로젝트는 시맨틱 버저닝(MAJOR.MINOR.PATCH)을 따릅니다.

| 구분 | 올라가는 때 | 예 |
| --- | --- | --- |
| MAJOR | 호환성이 깨지는 변경: `data.json`이나 설정 비호환, 수동 마이그레이션 필요, 기능 제거 | 호환 읽기 없이 설정 항목 이름 변경 |
| MINOR | 기능 추가, 창이나 탭 추가, 눈에 보이는 상호작용·시각 개편 | 바로가기 블록 추가 |
| PATCH | 버그 수정, 문구 수정, 스타일 미세 조정(동작은 그대로) | 색 단계가 덮이는 문제 수정, 여백 조정 |

버전의 기준은 `manifest.json`의 `version`이며, 릴리스 태그는 이와 같고 `v` 접두사를 붙이지 않습니다.

## [0.12.1] — 2026-09-01

### 변경

- 설정 문구에서 제작자 본인의 보관함을 가리키는 표현을 제거했습니다. '변경 기록'은 이제 '누구에게 맞는지, 어떻게 세는지'로 설명합니다. 같은 전제를 담은 코드 주석도 함께 정리했습니다(이 플러그인은 빌드 과정이 없어 `main.js`가 그대로 읽힙니다).
- README 언어에 맞춰 번역된 변경 기록을 `docs/`에 추가하고, 각 README에서 해당 언어로 링크했습니다. 루트의 `CHANGELOG.md`는 영어가 되었습니다.

## [0.12.0] — 2026-09-01

### 변경

- **`useMtime` 기본값을 켜짐으로 변경.** 대부분의 보관함에는 frontmatter 날짜도 파일명 날짜도 없는 노트가 많아, 꺼진 상태로는 히트맵이 거의 비고 설치 직후 빈 화면이 나옵니다. 동기화로 인한 가짜 급증은 눈에 보이고 설명 가능하며 스위치로 끌 수 있습니다. **기존 설정은 영향을 받지 않습니다.**
- 블록을 하나만 설정한 경우 바로가기 제목이 '바로가기 · 블록 이름'이 됩니다. 이전에는 블록이 하나면 1단계 탭을 그리지 않아 그 폴더 이름이 어디에도 보이지 않았습니다.

## [0.11.0] — 2026-09-01

### 추가

- 하위 폴더 선택에 '전체 선택'과 '전체 해제' 버튼을 추가했습니다.

### 변경

- 번역된 README를 `docs/`로 옮기고 루트에는 영어판만 두었습니다. 모든 README를 현재 사양에 맞게 갱신했습니다.

## [0.10.0] — 2026-09-01

### 추가

- 바로가기의 각 블록에서 폴더 바로 아래의 하위 폴더를 나열·선택해, 어떤 것을 2단계 탭으로 삼을지 정할 수 있습니다. 모두 선택하면 이후 추가된 하위 폴더도 자동으로 나타납니다.
- 선택 영역은 기본으로 접혀 있는 `<details>` 패널에 들어가며, 요약에 '전체 N개' 또는 'N개 중 n개 선택'이 표시됩니다.

### 변경

- **폴더 이름에서 숫자 접두사를 떼지 않고 이름을 그대로 표시합니다.** 이전 방식은 제작자의 명명 규칙에 맞춘 것으로, 다른 사용자에게는 `2024_Q1 Reports`가 `Reports`가 되는 등 숫자뿐 아니라 첫 단어까지 사라졌습니다. 짧은 이름이 필요하면 '표시 이름'에 직접 입력하세요.
- 설정 페이지의 바로가기 영역 왼쪽 끝을 제목·기본 설정 행과 맞췄습니다.

## [0.9.0] — 2026-08-29

### 추가

- Starbucks 외관의 탭에도 슬라이딩 하이라이트를 적용했습니다.
- 상단 내비게이션 바를 반투명 유리(`backdrop-filter`)로 만들었습니다. sticky라 아래로 내용이 흐르므로 흐림 효과가 의미를 가집니다.

### 변경

- **히트맵 방향을 뒤집어 왼쪽에서 오른쪽으로 '최신 → 과거'가 되었습니다.** 가로로 길 때 스크롤바가 왼쪽에 있는 상태에서 최신 데이터가 보입니다.
- 내비게이션 바 위쪽을 막아, 스크롤할 때 내용이 틈으로 비치지 않게 했습니다.

### 수정

- 탭을 바꿀 때 글자색이 슬라이더보다 먼저 바뀌던 문제를 고쳤습니다. 이전에는 흰 글자가 흰 배경 위에 0.2초가량 남아 읽히지 않았습니다.

## [0.8.1] — 2026-08-29

### 변경

- 히트맵의 `column-gap` / `row-gap`을 `gap`으로 합쳐 커뮤니티 심사 CSS lint의 오탐을 피했습니다.

## [0.8.0] — 2026-08-29

### 추가

- 인터페이스 언어를 3종에서 8종으로 확장(프랑스어·이탈리아어·일본어·한국어·스페인어 추가, 63개 항목을 각 언어로 완비).
- 탭 전환에 슬라이딩 하이라이트를 추가(4개 탭 그룹). `prefers-reduced-motion: reduce`에서는 자동으로 비활성화됩니다.

### 변경

- '시각적 폴더'를 '바로가기'로 이름 변경(8개 언어).
- Apple 외관 정비: 히트맵과 바로가기를 흰 바탕·둥근 모서리·얇은 테두리로 통일하고, 여백을 전반적으로 좁히고, 탭에서 테두리와 선택 링을 없앴습니다.

### 수정

- 탭 자체의 배경이 슬라이더를 가리던 문제를 고쳤습니다.
- `excludedPrefixes`를 바꿔도 노트 총계가 갱신되지 않던 문제를 고쳤습니다.

## [0.7.1] — 2026-08-26
