# Vault Dashboard X

[English](README.md) · [中文](README_zh.md) · **한국어** · [日本語](README_ja.md) · [Français](README_fr.md) · [Español](README_es.md) · [Italiano](README_it.md)

Obsidian 볼트를 위한 대시보드: 활동 히트맵, 폴더 분포 뷰, 구성 가능한 "시각적 폴더" 빠른 링크를 하나의 패널에 담았습니다.

## 기능

- **활동 히트맵** — GitHub 스타일의 기여 그리드로 볼트(또는 체인지로그)의 시간에 따른 활동도를 표시하며, `전체 / 30일 / 7일` 범위를 지원합니다.
- **폴더 분포** — 최상위 폴더별 노트 분해. 드릴다운 행, 상위 폴더 대비 비율 막대, "이번 달 새 항목" 개수를 제공합니다.
- **시각적 폴더** — 최대 5개의 구성 가능한 블록. 선택한 폴더의 하위 폴더를 탭으로 표시하고 최근 수정된 노트를 나열합니다.
- **두 가지 데이터 소스** — 범용 "노트 활동" 소스(모든 볼트에서 동작)와 마크다운 체인지로그용 선택적 "체인지로그" 파서.
- **세 가지 테마** — Apple, Y2K Console, Starbucks Café.
- **국제화** — 영어(기본값), 중국어 간체, 중국어 번체, 일본어, 한국어, 프랑스어, 스페인어, 이탈리아어.

## 데이터 소스

### 노트 활동(기본값)

각 노트는 하나의 "활동일"을 기여하며, 다음 폴백 체인으로 결정됩니다.

1. Frontmatter의 `updated` 필드(필드 이름은 구성 가능).
2. Frontmatter의 `created` / `date`.
3. 파일 이름의 `YYYY-MM-DD` 접두사.
4. 파일 수정 시간(`mtime`) — **기본적으로 꺼져 있음**; 설정에서 활성화.

노트 활동은 추가 설정 없이 모든 볼트에서 바로 작동합니다.

### 체인지로그

하나 이상의 체인지로그 파일에서 항목을 집계합니다. 파서는 `## YYYY-MM-DD` 섹션을 읽고 각 날짜 아래의 최상위 목록 항목을 세어 셉니다.

```markdown
## 2026-08-23

- 7월 보고서 게시
- 스타일 가이드의 오타 수정

> 참고: 날짜 섹션 아래의 인용구는 무시됩니다.
```

각 파일은 단일 노트이거나 폴더(내부의 모든 `.md` 파일, 비재귀)일 수 있습니다.

## 사용법

리본 아이콘 또는 **"대시보드 열기"** 명령으로 대시보드를 엽니다.

- **개요** 탭 — 히트맵과 요약 카드.
- **폴더** 탭 — 폴더 분포.
- 체인지로그 히트맵의 셀을 클릭하면 해당 날짜의 섹션으로 이동합니다(체인지로그 모드에서만).
- 폴더 행을 클릭하면 드릴다운합니다.

## 설정

| 설정 | 설명 |
| --- | --- |
| 언어 | 설정 페이지와 대시보드의 인터페이스 언어. |
| 모양 | 시각 스타일: Apple, Y2K Console, Starbucks Café. |

| 시각적 폴더 | 최대 5개 블록; 각각 폴더를 가리키고 하위 폴더와 최근 노트를 표시. |

## 설치

### 커뮤니티 디렉터리에서(게시 후)

**설정 → 커뮤니티 플러그인**에서 "Vault Dashboard X"를 설치한 후 활성화합니다.

### 수동

1. 최신 릴리스에서 `main.js`, `manifest.json`, `styles.css`를 다운로드합니다.
2. 볼트에 `.obsidian/plugins/vault-dashboard-x/` 폴더를 만듭니다.
3. 세 파일을 해당 폴더에 복사합니다.
4. **설정 → 커뮤니티 플러그인**에서 플러그인을 활성화합니다.

## 개발

**빌드 단계가 없습니다** — `main.js`가 플러그인 산출물입니다. 편집 후 Obsidian에서 플러그인을 비활성화하고 다시 활성화하거나(또는 `Reload app` 실행) 변경 사항을 적용하세요.

- 버전은 `npm version <patch|minor|major>`로 올립니다. `manifest.json`과 `versions.json`이 자동으로 동기화됩니다.
- 오프라인 데이터 계층 점검은 `node test/harness.js`로 실행합니다.

릴리스 태그는 **`manifest.json`의 `version`과 반드시 일치해야 하며 `v` 접두사를 붙이면 안 됩니다.** `main.js`, `manifest.json`, `styles.css`는 별도의 릴리스 자산으로 첨부됩니다.
